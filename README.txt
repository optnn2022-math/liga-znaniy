ОБНОВЛЕНИЕ КАРТИНКИ «ПИСЬМЕННЫЕ РАБОТЫ»

1. Распакуйте содержимое архива в корень проекта liga-znaniy с сохранением папок.
2. В терминале из корня проекта выполните:
   bash APPLY_WRITTEN_WORKS_IMAGE.sh
3. Проверьте страницу русского языка.
4. После проверки выполните git add / commit / push, команды будут показаны скриптом.
