# Математическая мастерская — 5 класс

Мастерская открывается по `math/workshop/index.html` или по новой ссылке на странице тем математики. Она дополняет основной курс и не заменяет уроки. Все пути относительные, включая возврат к математике: модуль подходит для GitHub Pages в `/liga-znaniy/`, размещения в корне другого домена и локального открытия `index.html`.

## Содержание

48 авторских заданий по восьми разделам: числа и числовой луч, делимость, НОД/НОК, действия, уравнения, движение, геометрия, дроби/проценты. В каждом разделе три тренировочных задания разных уровней, одно задание повышенной сложности, одно олимпиадное задание и одна лаборатория. Источники Смыкаловой и школы №57 не использовались: их проверенные формулировки и каталоги не были приложены к этой задаче.

Лаборатории включают отметку точки на луче, выбор чисел по двум признакам делимости, распределение карточек, выбор первого действия, весы, встречное движение, площадь на клетчатой бумаге и модель дроби. Действия доступны мышью, касанием и клавиатурой; перетаскивание не требуется.

В отдельном тесте 16 вопросов, по два на раздел. Первый отправленный ответ в рамках текущего прохождения изменить нельзя. При выходе в мастерскую тест продолжается с первого неотвеченного вопроса. Разбор открывается после всех вопросов. Новое прохождение завершённого теста не дублирует уже полученные голы.

## Обучение и прогресс

`tasks.js` содержит задания, ответы, две последовательные подсказки, проверенные решения и привязку разделов к номерам тем существующего курса. Темы мастерской доступны независимо от открытия уроков: это отдельная среда исследования, а не изменение условий доступа основного курса.

В тренировке последние три ответа по разделу влияют на порядок следующих заданий. Два самостоятельных правильных ответа предлагают второй уровень; три — третий. Две ошибки среди последних трёх возвращают первый уровень. Решение с подсказками не считается самостоятельным. Это простое правило подбора внутри небольшого банка, не диагностика всей школьной программы.

Результаты сохраняются только под `liga_math_workshop_v1`. Ключи уроков и их данные не меняются. За задание выдаётся один гол, за вопрос теста — ещё один; максимум 48 + 16 = 64. При каждом сохранении читается текущая запись, поэтому повторное открытие и одновременные вкладки не дублируют награды. Общий счётчик звёзд учитывает эти голы дополнительно к существующим.

Хранятся правильные/неправильные ответы, использованные подсказки, самостоятельные решения, дата последней практики, текущее задание и первый ответ каждого вопроса незавершённого теста. Ошибочный ответ или решение с помощью оставляет задание в маршруте повторения. Самостоятельный верный ответ при новом решении удаляет его из маршрута. Текст свободного объяснения не сохраняется и не оценивается.

Время работы учитывается только на экране задания или теста, пока вкладка видна; после 90 секунд без действий время не начисляется. Это приблизительное время работы в браузере, а не подтверждённая длительность обучения. При недоступном localStorage выводится уведомление и текущая сессия продолжает работать в памяти.

Отчёт для родителя показывает результаты только мастерской, рекомендации по разделам, активное время и последний тест. Его можно распечатать и выгрузить в JSON. Это открытая страница с локальным прогрессом, не защищённый аккаунт. Сервер, авторизация, синхронизация между устройствами и платежи не добавлены.

Тренер использует заранее подготовленные подсказки по текущему заданию. Подключения к LLM/API нет; серверный ИИ-репетитор потребует отдельной реализации с защищённым API-ключом. Секреты в клиентский код добавлять нельзя.

## Оформление и интеграция

Использованы утверждённые изображения из `math/lessons/06/images/`: фон стадиона и позы героя. У существующего урока не меняется геометрия CSS. Мастерская имеет собственную рабочую область примерно 3/4 экрана, героя справа, читаемые панели, отдельный экран каждого задания и отдельный экран теста. На телефоне герой находится над содержимым.

Из существующих файлов изменены только:

- `math/index.html` — добавлена ссылка в блок действий страницы тем;
- `shared/js/global-stars-v818.js` — добавлен учёт уникальных наград мастерской.

Файлы уроков, основная карта тем, ключи прогресса и главная страница не меняются. Для удаления мастерской достаточно убрать ссылку и её блок начисления из общего счётчика; удалять другие ключи localStorage не требуется.


## Загрузка

До запуска скриптов виден стартовый экран с кнопкой повторной загрузки. При задержке или ошибке загрузки сообщение предлагает обновить страницу. Скрипты и стили имеют общий номер версии в URL, чтобы браузер не использовал ранее закэшированные отсутствующие файлы. Повторная загрузка меняет этот номер и сохраняет маршрут текущего задания; прогресс не очищается.

## Проверка

Из корня репозитория: `node --test math/workshop/tests/*.test.cjs`.

Автоматические проверки охватывают ответы банка, лаборатории, числовой ввод, награды, сохранение, ошибки, подсказки, уровни, завершение и восстановление теста, защиту прежних ключей и общий счётчик. Дополнительно проверяются синтаксис скриптов и локальные ссылки относительно дерева репозитория. В этой среде управление браузером недоступно, поэтому визуальная проверка не выполнена.

Перед объединением ветки вручную проверьте страницу на компьютере и телефоне: открыть из тем → решить задание → получить подсказку → перезагрузить → продолжить → повторить ошибку → завершить тест → открыть отчёт → вернуться к математике. До объединения ветки GitHub Pages продолжает показывать исходную версию.
