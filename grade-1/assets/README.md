# Изображения для оформления Академии

Загружайте изображения в эту папку `grade-1/assets/` или распределяйте по подпапкам:

- `characters/` — Волшебница, единорог, их позы и эмоции.
- `backgrounds/` — сказочные фоны страниц.
- `locations/` — изображения предметных локаций и замков.
- `buttons/` — декоративные элементы кнопок.
- `rewards/` — звёзды, кристаллы и награды.
- `decor/` — декоративные элементы.

GitHub не хранит пустые папки: подпапка появится при загрузке в неё первого файла. Рекомендуемые форматы: PNG/WebP для персонажей с прозрачностью, WebP/JPG для фонов. Используйте понятные латинские имена файлов.
