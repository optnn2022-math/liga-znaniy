# Академия маленьких открытий — 1 класс

Отдельный раздел образовательной платформы для ученицы 7 лет.

## Предметы
- mathematics — математика
- handwriting — письмо
- reading — чтение
- russian — русский язык
- english — английский язык
- world — окружающий мир
- art — ИЗО
- crafts — труд
- music — музыка

## Планируемая структура
- `index.html` — главная страница Академии
- `assets/characters/` — Волшебница и единорог
- `assets/backgrounds/` — фоны и локации
- `assets/rewards/` — награды
- `assets/audio/` — аудио
- `subjects/<subject>/lessons/` — уроки предмета
- `shared/` — общие стили и механики
- `data/` — учебные данные

Папки создаются по мере добавления файлов. Раздел не изменяет действующие уроки других классов.
