МАТЕМАТИЧЕСКИЙ СПРИНТ — ЛИГА ЗНАНИЙ
Прототип 1.0

СОСТАВ
  index.html            интерфейс и игровая логика
  manifest.webmanifest  установка PWA на телефон
  sw.js                 кеширование для офлайн-доступа
  icons/                иконки 192px и 512px

КАК ПРОВЕРИТЬ
1. Откройте index.html в современном браузере.
2. Выберите режим, уровень и арифметические действия.
3. Нажмите «Начать тренировку».
4. После занятия можно выгрузить PDF-отчёт с результатами, ответами и ошибками.

КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES
1. Создайте отдельный репозиторий либо подпапку math-sprint в репозитории сайта.
2. Загрузите файлы с сохранением структуры (index.html, sw.js,
   manifest.webmanifest, icons/ должны лежать рядом).
3. В Settings → Pages выберите нужную ветку и папку публикации.
4. Откройте HTTPS-адрес. Можно добавить приложение на главный экран.
5. В основном сайте «Лига знаний» добавьте ссылку на эту страницу.

ПРИМЕЧАНИЯ
- Данные сохраняются только в текущем браузере через localStorage.
- Нет входа учеников, единой базы и кабинета преподавателя.
- Для установки PWA нужен опубликованный HTTPS-сайт (или localhost при разработке).
- Подключение к основной «Лиге знаний» и публикация не выполнялись.
- Примеры имеют целочисленные ответы; деление — без остатка.
- Во время спринта после ответа следующий пример появляется автоматически.
