ЛИГА ЗНАНИЙ — УСТНЫЙ СЧЁТ, ВЕРСИЯ 3.0 (ОБЕ ВЕРСИИ + СТАТИСТИКА)

ОТКРЫТЬ
index.html          Единое меню
stats.html          Общая статистика и журнал занятий
topics/index.html   Все 12 тематических тренажёров (версия 2.0)
general/index.html  Обобщающий математический спринт (первая версия)

НОВОЕ
- Тренировки сохраняются автоматически при завершении/остановке.
- Каждая новая тренировка хранит время, тему, уровень, правильные и ошибочные ответы, скорость ответа на каждый пример.
- Общий журнал за всё время / 7 дней / 30 дней с фильтром по двум тренажёрам.
- Динамика точности по 14 тренировкам, статистика по темам, рекорд скорости, типичные ошибки.
- Подробная карточка тренировки, PDF-отчёт с результатами, ответами и ошибками.
- Резервная копия JSON, импорт на другом устройстве, очистка всех результатов с подтверждением.
- Сохраняется совместимость с прежним локальным хранилищем v1 и v2. Старые записи без истории отображаются в итоговой статистике.

ХРАНЕНИЕ/ОГРАНИЧЕНИЯ
Данные хранятся только в localStorage этого браузера и происхождения (origin).
Данные НЕ синхронизируются между телефонами, не поступают преподавателю и не хранятся на сервере.
Для личных кабинетов и доступа педагога требуется авторизация + база данных; это не реализовано.
Занятия с ответами сохраняются до 450 записей в каждой ветке; браузер может ограничивать объём локального хранилища.
Рекомендуется регулярно выгружать JSON-бэкап. Не использовать режим инкогнито.
Публикация: загрузить содержимое архива в отдельный репозиторий GitHub Pages или папку сайта.
Для корректной работы общего localStorage открывать все страницы с ОДНОГО домена и https.
Для локальной проверки: python -m http.server 8765 и http://localhost:8765

ПРОВЕРКА
Приложение можно протестировать без регистрации и без сервера API.
