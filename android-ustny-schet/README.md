# Лига знаний — Устный счёт (Android)
Самостоятельное приложение версии 6.0 для Android 7+ (API 24). В основе — сохранённый автономный HTML-файл `ustny-schet/v6-0.html`.

## Возможности
- Работает **без интернета сразу после установки**.
- Спринт, 16 тем, планы на 7/30 дней и статистика, сохранение в Android WebView localStorage.
- Экспорт PDF через системную печать «Сохранить как PDF», экспорт/импорт JSON через системный выбор файлов.
- Автозагрузка новых HTML-версий из GitHub Pages **без переустановки APK**. Загруженная версия применяется при следующем запуске; данные остаются на том же внутреннем origin `https://appassets.androidplatform.net`.
- Версия APK не изменяет содержимое публичного сайта.

## Выпуск APK
GitHub Actions: `.github/workflows/build-ustny-apk.yml` — собирает установочный **debug APK** и публикует его в GitHub Releases. Для Google Play понадобится релизная сборка с постоянным закрытым ключом подписи в GitHub Actions Secrets; debug-подпись сборочного сервера не годится для обновления через установленный APK.

## Обновление HTML
1. Опубликовать новую автономную страницу `ustny-schet/vX-Y.html`.
2. Изменить `ustny-schet/android-version.json`: увеличить `build`, указать имя новой страницы в `file`. Счётчик build должен расти.
3. APK проверит manifest при открытии, получит новую HTML-версию и покажет уведомление. Данные localStorage остаются прежними.
4. При проблемах с сетью APK продолжает использовать последнюю успешно загруженную версию или встроенную 6.0.

Для переноса результатов из браузера на Android используйте экспорт и импорт резервной копии JSON на странице статистики.
