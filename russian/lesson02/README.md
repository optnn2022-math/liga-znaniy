# Русский язык — урок 2

## Итоговая утверждённая версия
Страница «Словарная лаборатория» зафиксирована как итоговый вариант оформления.

### ВАЖНО ДЛЯ ДАЛЬНЕЙШЕЙ РАЗРАБОТКИ
- **Только страница «Словарная лаборатория»** имеет специальный библиотечный фон и отдельное визуальное оформление.
- **Все остальные страницы урока должны создаваться с ОСНОВНЫМ ФОНОМ САЙТА «Лига знаний»**, а не с фоном библиотеки.
- Не переносить библиотечный фон лаборатории на остальные этапы урока.
- Сохранять общую верхнюю панель, навигацию урока, счёт голов и кнопку «К темам».
- Утверждённую механику сортировки лаборатории не менять без отдельного решения.

## Структура
- `index.html` — версия для GitHub Pages.
- `assets/css/lesson02.css` — стили.
- `assets/js/lesson02.js` — интерактив и логика.
- `assets/images/` — изображения урока.
- `source/` — резервная самодостаточная утверждённая HTML-версия.

## Видео
Видео Rutube подключено через iframe и требует интернет-соединения.

## Для GitHub
Папку `russian/lesson02/` можно разместить в репозитории проекта с сохранением структуры.
Точка входа урока: `russian/lesson02/index.html`.
