Лига знаний — патч русского языка

Что меняет:
1. Возвращает карточку «Письменные работы» в правую колонку.
2. Возвращает утверждённое красно-бордовое оформление.
3. Убирает с главной страницы отдельные синие мини-карточки «Диктанты / Изложения / Сочинения / Контрольные работы».
4. Кнопка «Открыть раздел» ведёт в russian/written-works.html — существующая иерархия письменных работ сохраняется.
5. Список тем русского языка и логика подсчёта результата урока не изменяются.

Установка из корня репозитория:
unzip -o Liga_Znaniy_RUSSIAN_WRITTEN_RED_CARD_PATCH.zip
bash APPLY_RUSSIAN_WRITTEN_RED_CARD.sh
bash UPDATE_SITE.sh

Перед изменением автоматически создаётся russian/index.html.bak-written-red-card
